# Mall Customer Segmentation

A machine learning project that uses K-Means clustering to group mall customers based on their annual income and spending score.

## Project Overview
Customer segmentation helps businesses understand different customer groups and plan more effective marketing strategies.

## Features
- Explore customer data
- Analyze annual income and spending scores
- Apply K-Means clustering to identify customer segments
- Visualize customer groups

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## How to Run
1. Clone or download this repository.
2. Install the required libraries:
   ```bash
   pip install pandas numpy matplotlib seaborn scikit-learn jupyter
   ```
3. Open the notebook in Jupyter:
   ```bash
   jupyter notebook
   ```
4. Run the notebook cells in order.

## Dataset
The project uses mall customer data, typically including customer ID, gender, age, annual income, and spending score. Add the dataset file to the repository if it is not already included.

## Project Goal
To identify customer groups with similar spending behavior and support data-driven marketing decisions.
